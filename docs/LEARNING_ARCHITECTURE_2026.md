# AI Lab 2026 — образовательная архитектура Zero → MyGPT

## Главная цель

Ученик приходит без знаний об искусственном интеллекте и без обязательного опыта программирования. В финале он должен уметь:

1. объяснить, чем обычная программа отличается от обучаемой модели;
2. написать основные механизмы нейросети собственными руками;
3. обучить небольшую нейросеть на данных;
4. объяснить токенизацию, embeddings, attention и Transformer;
5. собрать и обучить собственную маленькую GPT-подобную языковую модель;
6. превратить её в простого диалогового ассистента;
7. провести eval, описать ограничения и оформить Model Card.

Курс считается успешным не тогда, когда ученик «прошёл 100% экранов», а когда у него появился работающий проект `MyAI`, компоненты которого он может объяснить и изменить.

---

## Педагогический стандарт

Каждый урок проектируется в последовательности:

**QUESTION → HYPOTHESIS → CONFLICT → DISCOVERY → EXPLAIN → VISUALIZE → BY HAND → MATH → CODE → TEST → BREAK → FIX → TRANSFER → BUILD MyAI**

Не каждый урок обязан содержать все 15 стадий, но обязательны четыре результата:

- **До урока:** что ученик ещё не умеет/не понимает?
- **После урока:** что он может объяснить своими словами?
- **Действие:** что он теперь умеет сделать без подсказки?
- **Артефакт:** какой реальный фрагмент `MyAI` он построил?

Если нет хорошего ответа хотя бы на один пункт — это демонстрация, а не урок.

### Правила введения сложности

- проблема появляется раньше термина;
- визуальная модель раньше формулы;
- ручной расчёт раньше автоматизации;
- код появляется только когда он решает уже понятную проблему;
- математика имеет основной маршрут и необязательный `Открой капот`;
- определение не является доказательством знания;
- контроль требует переноса на новую задачу;
- ошибки ученика используются как учебный материал.

# Сквозная траектория

## Этап 0. Компьютер выполняет инструкции

**Вопрос:** откуда программа знает, что делать?

Ученик открывает понятия входа, выхода, правила, алгоритма, данных и функции. Он видит фундаментальное различие:

> В обычной программе человек формулирует правило. В машинном обучении правило частично извлекается из примеров.

**MyAI:** `01_rule.py`, `02_predict.py`

## Этап 1. Обучаемое правило

**Вопрос:** можно ли описать неизвестное правило числами и подобрать эти числа по примерам?

Появляются `x`, `prediction`, параметры `w`, `b`, пример `prediction = x * w + b`.

**MyAI:** `03_parameters.py`

## Этап 2. Ошибка и обучение

**Вопрос:** как понять, что одна версия модели лучше другой?

Prediction → target → error → loss → изменение параметров → новый prediction. Затем интуиция направления изменения, learning rate и training loop.

**MyAI:** `04_loss.py`, `05_improve.py`, `06_train.py`

## Этап 3. Первый нейрон и сеть

Только после того как ученик уже обучал формулу, раскрывается название вычислительного элемента — искусственный нейрон. Затем несколько входов, weights, bias, activation, layer, MLP.

**MyAI:** `07_neuron.py`, `08_layer.py`, `09_mlp.py`

## Этап 4. Backprop и autograd

**Вопрос:** как обновлять тысячи и миллионы параметров, а не один `w`?

Производная как чувствительность, локальные градиенты, chain rule, computational graph, backpropagation, micrograd-подобный scalar autograd.

**MyAI:** `10_value.py`, `11_backward.py`, `12_autograd_mlp.py`

## Этап 5. Настоящее обучение на данных

Dataset, features, labels, train/validation/test, batches, epochs, learning rate, overfitting, regularization, metrics. Переход NumPy → PyTorch после понимания ручного механизма.

**MyAI:** `13_dataset.py`, `14_train_classifier.py`, `15_eval.py`

## Этап 6. Текст становится числами

Bytes, Unicode, characters, vocabulary, tokenization, BPE, encode/decode. Ученик пишет минимальный tokenizer и сравнивает разные разбиения.

**MyAI:** `16_tokenizer.py`

## Этап 7. Первая языковая модель

Next-token prediction как конкретная задача. Частоты, probabilities, bigram table, sampling, negative log-likelihood/cross-entropy.

**MyAI:** `17_bigram.py`, `18_generate.py`

## Этап 8. Embeddings и контекст

One-hot недостаточен → trainable embeddings. Position, context window, batching sequences.

**MyAI:** `19_embeddings.py`, `20_context.py`

## Этап 9. Attention

**Проблема:** фиксированного локального контекста недостаточно.

Similarity → weighted aggregation → Q/K/V → scaled dot-product → softmax → causal mask → self-attention → multi-head attention.

**MyAI:** `21_attention.py`, `22_multihead.py`

## Этап 10. Transformer

Residual connections, normalization, MLP/SwiGLU concept, Transformer block, stack, logits, parameter counting.

**MyAI:** `23_block.py`, `24_transformer.py`

## Этап 11. TinyGPT

Полная сборка: tokenizer → batches → embeddings → Transformer → logits → loss → optimizer → checkpoints → generation.

**MyAI:** `25_gpt.py`, `26_train_gpt.py`, `27_sample.py`

## Этап 12. MyGPT

Работа с более серьёзным датасетом и GPU: reproducibility, checkpoints, validation curves, sampling parameters, failure analysis.

**MyAI:** полноценный `mygpt/` пакет + checkpoint.

## Этап 13. Из модели в ассистента

Base model vs instruct model, chat templates, instruction datasets, SFT, preference/alignment overview, hallucinations, system instruction, evals.

**MyAI:** `assistant/`, SFT dataset, assistant checkpoint/adaptor.

## Этап 14. Знания и инструменты

Embeddings for retrieval, semantic search, RAG pipeline, tool calling, agent loop, memory boundaries, prompt injection.

**MyAI:** `rag.py`, `tools.py`, `agent.py`.

## Этап 15. Systems + Research Defense

GPU memory, batching, KV cache, inference, quantization overview, latency/throughput. Финальный eval suite, Model Card, ограничения, безопасность, защита проекта.

**Финал:** ученик демонстрирует модель, объясняет архитектуру, показывает неудачные эксперименты и отвечает на вопросы по ограничениям.

# Первые 7 уроков — обязательный старт

Эти уроки должны быть понятны ученику, который впервые видит машинное обучение и почти не программировал.

### 01. Ты знаешь правило. Компьютер — нет.

- **До:** «ИИ — это программа, которая сама всё знает».
- **После:** различает правило, пример и предсказание.
- **Действие:** находит закономерность и применяет её к новому входу.
- **MyAI:** первая спецификация функции `predict`.

### 02. Правила или примеры?

- **До:** считает, что любую интеллектуальную систему нужно полностью описать `ЕСЛИ → ТО`.
- **После:** объясняет разницу между программированием правил и обучением по примерам.
- **Действие:** определяет, где разумнее написать правило, а где собрать данные.
- **MyAI:** `01_rule.py`.

### 03. Первое правило на Python

- **До:** Python-код выглядит как чужой язык.
- **После:** понимает переменную, арифметику, `return`, функцию и вызов функции.
- **Действие:** дописывает и запускает `predict(x)`.
- **MyAI:** `02_predict.py`.

### 04. Модель можно настраивать числами

- **До:** правило фиксировано человеком.
- **После:** понимает параметры `w` и `b` как изменяемые числа модели.
- **Действие:** вручную настраивает `w` и `b` под несколько примеров.
- **MyAI:** `03_parameters.py`.

### 05. Насколько модель ошиблась?

- **До:** видит только «правильно / неправильно».
- **После:** объясняет error и loss как числовую меру качества.
- **Действие:** вычисляет ошибку для нового примера и сравнивает две модели.
- **MyAI:** `04_loss.py`.

### 06. В какую сторону менять параметр?

- **До:** может только угадывать новое значение `w`.
- **После:** понимает идею чувствительности: небольшое изменение параметра меняет loss.
- **Действие:** сравнивает `loss(w-ε)` и `loss(w+ε)` и выбирает направление улучшения.
- **MyAI:** `05_improve.py`.

### 07. Первое настоящее обучение

- **До:** параметры меняет человек.
- **После:** может проговорить цикл обучения: prediction → loss → update → repeat.
- **Действие:** запускает несколько шагов обучения и наблюдает уменьшение loss.
- **MyAI:** `06_train.py`.

Только после этого курса разрешено вводить термин **«искусственный нейрон»**.

# Что замораживаем

До готовности первых 7 уроков не развиваем:

- новые художественные сцены;
- новые персонажи;
- сложную карту Технопарка;
- дополнительные визуальные эффекты;
- декоративную геймификацию.

Дизайн используется как инфраструктура. Главный критерий следующей итерации — **чему научился ребёнок**, а не насколько эффектно выглядит экран.
