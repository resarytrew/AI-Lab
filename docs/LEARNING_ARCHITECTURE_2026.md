# AI Lab 2026 — от вопроса об интеллекте до собственной MyGPT

## Главный замысел

AI Lab — не курс «быстрого входа в нейросети» и не набор эффектных демонстраций.

Ученик начинает как любопытный школьник, который ещё не обязан знать программирование, линейную алгебру или машинное обучение. Финальная цель — собственная небольшая GPT-подобная модель, которую ученик не просто запускает, а может разобрать, изменить, обучить, оценить и защитить.

Идентичность ученика развивается так:

**Новичок → Исследователь → Экспериментатор → Разработчик → Инженер → Автор MyGPT → Участник Research Defense.**

---

## Педагогический закон курса

Новое понятие не появляется потому, что «пришло время изучить термин».

Оно появляется только тогда, когда предыдущего объяснения уже недостаточно:

**чтобы понять A, нам понадобилось B; чтобы понять B, пришлось различить C и D.**

Поэтому базовый цикл урока:

**QUESTION → HYPOTHESIS → CONFLICT → DISCOVERY → EXPLAIN → VISUALIZE → BY HAND → MATH → CODE → BREAK → FIX → TRANSFER → BUILD MyAI**

Ключевые правила:

1. вопрос раньше определения;
2. ученик сначала высказывает гипотезу;
3. контрпример ломает слишком простой ответ;
4. понятие вводится как необходимый инструмент;
5. конкретное предшествует абстрактному;
6. визуальная модель предшествует формуле;
7. ручное действие предшествует автоматизации;
8. математика появляется после смысла;
9. код появляется после понимания механизма;
10. сложная математика углубляет, но не блокирует основной путь;
11. проверка требует переноса на новую ситуацию;
12. каждый урок расширяет реальную способность MyAI.

---

## Один курс, несколько уровней глубины

Не делаем отдельный «лёгкий» и «сложный» курс.

### Core path

Обязательное понимание идеи и механизма. Этого пути достаточно, чтобы двигаться дальше.

### Открой капот

Настоящая математика и внутренняя механика: формулы, выводы, численные расчёты.

### Engineer

Реализация механизма на Python / NumPy / PyTorch.

### Researcher

Альтернативы, абляции, пограничные случаи, исследовательские вопросы и мини-эксперименты.

# Сквозная архитектура

## 0. Лаборатория интеллекта

**Вопрос:** что вообще делает систему умной?

Не начинаем с нейрона, Python или формулы. Сначала ученик сравнивает калькулятор, навигатор, распознающую систему и языковую модель и пытается сформулировать наблюдаемые способности: использовать знания, понимать контекст, учиться, рассуждать, планировать.

**MyAI:** `01_intelligence_criteria.md`.

## 1. Архив данных и знаний

**Вопрос:** как машина получает мир и откуда берётся смысл?

Сырые значения → контекст → информация → вывод/знание.

**MyAI:** `02_meaning_map.json`.

## 2. Лаборатория правил

**Вопрос:** как передать машине знание явно?

Факты, условия, правила `ЕСЛИ → ТО`, простой вывод, маленький rule engine.

**MyAI:** `03_rule_engine.py`.

Затем обязательный конфликт: правила хорошо работают там, где мир можно перечислить. На распознавании, языке и неоднозначных ситуациях появляются тысячи исключений.

**MyAI:** `04_rule_limits.md`.

## 3. Лаборатория обучения

**Вопрос:** можно ли не программировать все правила, а дать системе примеры?

Сначала различаем запоминание и обобщение. Только после этого появляются обучающие примеры.

**MyAI:** `05_examples.csv`.

Далее причинная цепочка:

**примеры → параметры → prediction → error/loss → автоматический поиск улучшения → направление изменения → training loop.**

**MyAI:**

- `06_parameters.py`
- `07_loss.py`
- `08_search_update.py`
- `09_gradient_direction.py`
- `10_train.py`

## 4. Нейролаборатория

Только теперь раскрываем, что знакомый обучаемый вычислительный элемент очень близок к искусственному нейрону.

Inputs → weights → bias → activation → output.

Несколько нейронов образуют слой и могут учиться разным представлениям одних входов.

**MyAI:**

- `11_neuron.py`
- `12_layer.py`

## 5. Лаборатория языка

**Вопрос:** как нейросети вообще увидеть текст?

Текст → единицы → vocabulary → token IDs → encode/decode.

**MyAI:** `13_tokenizer.py`.

## 6. Первая языковая модель

**Вопрос:** можно ли превратить язык в повторяющуюся задачу предсказания следующего токена?

Counts → probabilities → next-token prediction → sampling → bigram transitions.

**MyAI:**

- `14_next_token.py`
- `15_bigram_lm.py`

Финальный конфликт первой дуги: bigram уже генерирует, но видит слишком короткий контекст.

Именно этот провал открывает следующую часть курса.

## 7. Глубокое обучение и обобщение

Несколько слоёв, nonlinear activation, MLP, computational graph, derivatives, chain rule, backpropagation, autograd. Затем train/validation/test, overfitting, batches, epochs, PyTorch.

Цель этого этапа — дать ученику механизм масштабирования от нескольких ручных параметров к большим обучаемым сетям.

## 8. Embeddings и контекст

One-hot и простые ID недостаточны → trainable embeddings → position → context window.

## 9. Attention

Сначала языковая проблема:

> какую часть предложения нужно учитывать, чтобы продолжить его правильно?

Только после интуитивных связей слов появляются similarity, weighted aggregation, Q/K/V, softmax и causal mask.

## 10. Transformer

Self-attention → multi-head attention → residual → normalization → MLP → Transformer block → stack.

## 11. TinyGPT

Tokenizer → batches → embeddings → Transformer → logits → loss → optimizer → checkpoints → generation.

Ученик впервые собирает целую GPT-подобную модель из знакомых деталей.

## 12. MyGPT

Более серьёзный датасет, GPU, reproducibility, checkpoints, validation curves, sampling, failure analysis.

## 13. Из модели в ассистента

Base model vs instruct model, chat format, SFT, preference/alignment overview, hallucinations, evals.

## 14. RAG, Tools, Agents

Retrieval, external knowledge, semantic search, tool calling, agent loop, boundaries, prompt injection.

## 15. Systems + Research Defense

KV cache, batching, inference, memory, quantization, latency/throughput. Финальный Model Card, eval suite и защита проекта.

# Первые 15 уроков

Эта последовательность является обязательной. Переставлять параметры или нейрон в начало запрещено, потому что тогда термин появляется раньше причины.

1. **Умная ли машина?** — скорость ≠ интеллект; критерии интеллектуальной системы.
2. **От данных к смыслу** — данные → контекст → информация → знание.
3. **Как дать машине правило?** — `ЕСЛИ → ТО`, первый rule engine.
4. **Где правила ломаются?** — контрпримеры, исключения, хрупкость ручных правил.
5. **Может ли машина найти правило сама?** — примеры, запоминание vs обобщение.
6. **Что именно машина может менять?** — параметры `w`, `b`.
7. **Насколько модель ошиблась?** — error и loss.
8. **Можно ли улучшать модель автоматически?** — поиск параметров по loss.
9. **Куда менять параметр?** — чувствительность и направление уменьшения ошибки.
10. **Первое настоящее обучение** — prediction → loss → update → repeat.
11. **Что мы только что построили? Первый нейрон** — inputs, weights, bias, activation.
12. **Одного нейрона мало** — несколько нейронов и слой.
13. **Как нейросети увидеть текст?** — tokenizer и token IDs.
14. **Что будет следующим?** — распределение следующего токена.
15. **Первая языковая модель** — bigram LM и генерация.

После урока 15 ученик уже не просто «слышал про ИИ». У него есть причинная цепочка от критерия интеллекта до первой генерирующей модели.

# Стандарт результата каждого урока

Урок не считается завершённым, если ученик только выбрал правильный вариант.

Для каждого урока должны быть ответы на четыре вопроса:

- **Что ученик не понимал до урока?**
- **Что теперь может объяснить своими словами?**
- **Что теперь может сделать в новой ситуации?**
- **Какую способность или рабочий артефакт получил MyAI?**

Определение понятия само по себе не является доказательством обучения.

# Что замораживаем

Пока первые 15 уроков не доказали свою образовательную ценность, не расширяем декоративную часть продукта:

- новые фоновые сцены;
- новых персонажей;
- карту ради карты;
- XP и декоративные награды;
- визуальные эффекты без педагогической функции.

Технопарк остаётся сюжетной рамкой, но каждая «лаборатория» существует только потому, что в ней возникает новая проблема и открывается новый механизм.

Главный вопрос команды на каждой итерации:

> **Что ученик после этого экрана сможет понять, сделать, сломать, исправить и применить сам?**
